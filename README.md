## 这个“原生”到底原生在哪，买完怎么自己验

原生 IP 指由地区互联网注册机构（北美的 IP 归 ARIN 管）分配给当地运营商、并且确实在该地区使用的地址。广播 IP 是把 IP 段注册在甲国、再用 BGP 宣告到乙国使用，数据库定位容易漂移，平台风控看到的表现也不稳定。

这里有个概念要分清：**原生 IP 不等于住宅 IP**。住宅属性取决于这条 IP 是接在家庭宽带上还是摆在机房里。数据中心里的原生地址，照样会被标成机房类型。所以看到“原生住宅 IP”这种说法，先拆开看：原生说的是归属地一致，住宅说的是接入方式，两件事。

WePC 加拿大节点的第三方实测结果是 ASN 归属本地、不是广播 IP，这支撑“原生 IPv4”的说法，支撑不了“家宽”。把它当成一条干净的加拿大机房原生 IP 来看待，预期才对。

拿到机器后，72 小时内自己验一遍，三步：

1. **whois 查注册国家**。IP 的注册国应该是加拿大。
2. **查 ASN 归属**。用 IPinfo 或 ip-api 看 ASN 对应的运营商及其所在地，和 whois 对得上才算过。
3. **多库交叉比对定位**。MaxMind GeoIP、IP2Location、ping0 各查一次，三个库给的国家和城市一致，基本可以确认。Scamalytics、IPQualityScore 可以顺带看风险评分和代理标记。

再做两项实测：在机器上 `mtr` 到加拿大本地目标，延迟应该很低、路径不出境绕行；跑一下流媒体解锁脚本，看 Netflix、Disney+ 落区是否正确。数据库有更新延迟，单个站点判断也可能出错，多看几个结果再下结论。
